# Rally portable synthetic sample

From the repository root: `python3 -m http.server 8000 --bind 127.0.0.1 --directory demo`, then open http://127.0.0.1:8000/ . Python 3 is the only requirement for this path. Do not use file://; ES modules require HTTP.

The normal Rally home/Create meeting/live meeting/report interface, backed by an in-memory simulator instead of live services. Create a sample meeting, confirm the simulation acknowledgment and start it to watch a fictional engineering conversation flow. A completed example in history provides the full report immediately. Authored fictional agenda, transcript, replies and report. No live inference, ASR, recording, account or meeting connection. Speech is prerecorded from Meta MMS, FastSpeech2 and Seamless; see demo-audio/manifest.json and its README. Start unlocks audio; use Settings → Demo audio to silence it. This is an interaction sample, not evidence of model latency/accuracy. The real app source, integration setup, recorded-video provenance and component licensing boundaries are documented in the root README and docs. Bundle hashes/source paths: provenance.json.
