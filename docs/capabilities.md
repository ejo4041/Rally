# Capabilities and evaluation paths

| Capability | Full application | Credential-free sample |
| --- | --- | --- |
| Agenda → editable plan | Muse Spark using the operator's key | Authored sample plan |
| Streaming transcript | Muse Voice Transcribe from captured audio | Scripted partial/final text |
| Speaker identification | Human naming of anonymous session labels | Fictional Alex, Priya and Sam |
| Rally guidance and questions | Real model replies with participation controls | Scripted replies |
| Spoken replies | Provisioned speech adapter and playback route | Prerecorded Meta voices |
| Teams presence | Linux guest browser, virtual media and host admission | No meeting connection |
| Evidence-linked report | Model report over saved transcript | Fictional report over sample turns |
| PDF / JSON | Real browser print/export | Sample print/export |
| Report sharing | Named Rally users, read access and revocation | In-memory demonstration |
| Accounts / MFA | Invited users with mandatory enrollment | No authentication or private data |
| WhatsApp | Reviewed follow-up draft; joining experimental | Sample draft only |

## Important boundaries

- The animated presence reflects agenda guidance. It does not infer emotion or personality from faces.
- Anonymous speaker labels need human identification and can be wrong. They are not verified account identities.
- Reports are model interpretations for review. Missing owners/dates stay unresolved rather than being invented.
- Teams audio has capture/playback and echo-handling limitations; the dashboard and meeting participant have separate lifecycles. Use the host controls to end participation explicitly.
- The sample is useful for workflow evaluation, not an accuracy benchmark or live latency measurement. Its sharing controls do not grant access to any real report.
- Speech and Teams provisioning are separate from basic browser capture. Full own-key setup requires reachable package/model services and account entitlement. See [setup verification](judge-setup-verification-2026-11-03.md) for the measured checks and remaining install limitations.
