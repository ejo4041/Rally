# Real-provider endurance experiment

The gated `apps/rally-api/scripts/provider-endurance.ts` exercises the current meeting engine, actual Muse transcription/preparation/live reasoning/reporting, actual Seamless streamed speech and local LiveKit transport. Audio is authored synthetic speech generated by local pinned Meta MMS. It does not join Teams, record people, test remote camera rendering or establish human diarization accuracy. A real Teams run still requires a fresh invite, consent and host admission.

Input phrases cover a conditional release, drift/recovery, missing/proposed/accepted ownership, corrected deadlines and wrap-up. The source feeds real PCM through a native LiveKit publication at normal audio cadence. The production receiver/ASR adapter processes that stream. A second audio subscription measures actual approved output. The real reasoning cadence remains ten seconds. The test ends capture, drains final speech and requests the normal complete report. Report input turn/character counts are compared with canonical storage.

## Bounds and evidence

Default duration is 65 minutes, crossing the actual 55-minute ASR policy. Runtime allows 1–70 minutes. The isolated SQLite budget is at most $6 for Muse, with no automatic provider retries. Speech requests are separately capped at twelve; reaching the cap disables additional voice while transcription/reasoning continue. Their AWS infrastructure cost remains unknown and is never included in the Muse grant remainder. Unknown Muse costs, capture failure or unexpected media gaps stop the run for reconciliation.

An explicit `RALLY_PROVIDER_ENDURANCE_APPROVED=1` is required. Use distinct validated `RALLY_ENDURANCE_NAME` values; an existing run directory is retained and cannot be silently overwritten/restarted. `RALLY_ENDURANCE_MINUTES`, `RALLY_ENDURANCE_ROTATION_MS`, `RALLY_ENDURANCE_BUDGET` and `RALLY_ENDURANCE_SPEECH_LIMIT` are bounded. The separate authored-input builder makes no paid calls. No production database or service is modified.

The two-minute pilot uses a one-minute handoff, a $0.75 Muse ceiling and two speech requests. Its terminal result passed: two actual ASR sessions, eight finalized turns, eleven accepted live checks, one rejected stale result, streamed output energy and a completed real report. Settled Muse cost was $0.17267055, unknown Muse costs zero. Two AWS speech requests have unknown infrastructure cost. This does not establish 65-minute endurance.

A running long-test report is not a pass. Inspect terminal state, elapsed wall time, source revision, actual session handoff, complete report input, output delivery, resource samples and settled usage before documenting completion. Operator-requested shutdown is recorded as stopped. The source/test state is isolated from the public app.

The [long-turn correction](long-turn-handling.md) has independent real-model checks over synthetic long text; real ASR may choose shorter segments during endurance. Do not claim the run exercised a long finalized window unless its measurements show one.

## October 31 completed run

The 65-minute run passed on application source `51677f7`; its complete wall runtime was about 67 minutes including preparation and the final report. [Terminal measurements](research/provider-endurance-65-minute-2026-10-31.json). Actual Muse ASR crossed the normal 55-minute restart: two sessions, one expected continuity warning, nineteen finalized turns. The largest turn was 25,169 characters; 319 accepted checks used labeled long-turn windows. Of 390 checks, 389 were accepted and one was rejected near shutdown.

The report received all 19 canonical turns and all 56,044 characters; decision/action evidence IDs resolve to stored turns. Review confirmed that conditional release stayed conditional, the corrected Thursday-at-three deadline survived, and third-person ownership remained a proposal. This is a scenario observation, not a general accuracy guarantee.

Normal-cadence input stayed approximately 32,000 bytes/second. Sampled process RSS ranged 231–247 MB. Eight actual Seamless requests completed and the independent LiveKit receiver measured 2,689,920 PCM bytes with nonzero energy. Muse usage settled across 394 rows at **$3.28526990**, unknown0/running0; AWS infrastructure cost remains unknown. The owned transient service exited successfully and production services remain active on the long-turn release.

This is current-code real-provider endurance with synthetic speech. It does not close the real Teams/human meeting acceptance item: admission, remote camera/audio, overlap/echo, roster identity, network interruption and host/recipient report access still need a fresh consented call.
